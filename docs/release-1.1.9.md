# 1.1.9 版本发布说明

发布日期：2026-10-07。本补丁版本包含第四轮审查确认的 8 项缺陷修复。

## 更新内容

- 字幕切换语言或翻译轨道后，等待新响应期间立即撤销旧轨道显示；同轨刷新保留有效字幕，其他视频预取不影响当前显示，最新请求失败可恢复有效缓存。
- 下载确认等待期间持续保持动作互斥，取消或异常后可重试；注销和重新初始化后，旧异步结果不会释放新动作的执行锁。
- 模态框补齐语义、名称、初始焦点、Tab 顺序、嵌套弹窗和关闭恢复；内部控件可处理键盘事件，弹窗活动时背景快捷键暂停；关闭标签覆盖 33 种语言。
- JSON3 字幕事件提前到时间原点之前时，同步裁剪片段相对偏移，保持绝对时间一致。
- 字幕正文改写保留响应实例元数据和 clone 读取行为，协调失效表示头；XHR 先读头部再读正文时保持一致，复用和停用后恢复原生方法。
- Tabview 字号统一为 10–24px，按钮通知使用实际应用值；频道简介预览支持编码后的国际化 handle、合法分隔符及带查询和片段的 About 路径。
- 仓库安装入口、版本文案与发布说明同步到 1.1.9。

## 安装与升级

在 Tampermonkey 或 Violentmonkey 中安装发布附件 `youtube-turbo.user.js`。已有配置保持兼容。
