# 全项目缺陷修复方案

## 目标与验收

落实 [缺陷报告](project-bug-audit-report.md) 的 B01–B19，保留现有功能 ID、功能顺序、设置接口、页面与沙箱隔离，以及事件驱动的观察器边界。每个确认缺陷必须有对应行为回归；交付时类型检查、完整测试和生产构建通过。依赖真实 YouTube 时序的条件性风险单独标明现场验证状态。

## 修复设计

### 当前页面 DOM 归属（B01）

以当前路由和可见页面根解析视频、播放器、标题，排除隐藏保留页。Shorts 限定活跃 reel，媒体节点尚未挂载时等待就绪。迷你播放器仅在其处于活跃状态时作为回退。WeakRef 缓存复用句柄并检查实际媒体根的包含关系与活跃状态，路由事件继续原子失效。测试同时创建隐藏旧页与活跃页，并覆盖 Shorts 活跃节点切换、迷你播放器及现有播放器兼容路径。

### 功能设置持久化（B02、B03）

为每个功能提供独立存储键，修改一个功能只写入该键；旧整对象键作为未设置功能的兼容读取来源。读取时不写迁移数据或默认值，保留旧键，独立键存在时具有优先级。监听独立键及旧配置键，通知视为重新读取当前配置的信号；同一功能的并发修改遵循最后持久化值。

保留远端读取失败的待同步标记，在新通知、显式刷新或页面恢复可见时重读，不引入轮询。初始化失败时释放本轮监听资源；保持 target/applied、hook 串行化、requiresReload 和设置错误反馈契约。

### 页面等待与导航资源（B04–B06）

未定义自定义元素的底层等待表共享到页面生命周期，消费者仍通过 AbortSignal 撤销。各次 IIFE 不重复登记同一标签的底层 continuation，元素定义后结算全部有效消费者并释放记录。

About 导航的延迟任务在实际执行时核对 token，新导航及功能销毁取消旧监听和定时器。元数据缩放类依据当前测量结果同时添加和移除。保持原型补丁的持久化安装与生命周期所有权语义。

### 资讯镜像与字号投影（B07–B09、B18）

按源节点登记数据反射观察器，重复同步复用或替换已有绑定，销毁时断开全部资源。镜像数据更新以有效变更通知为准，避免仅比较对象引用漏掉就地修改。

分别记录拓扑修复与数据同步的待处理状态；统一微任务冲刷所有工作，生命周期结束后任务失效。每次渲染新的 Tab 面板时应用已保存字号，内部状态与实际样式一致。

### 字幕身份、时间线与隐藏所有权（B10–B12）

拦截响应与当前视频身份关联，fetch 与 XHR 按请求发起顺序共享每视频最新轨道所有权。旧响应仍可缓存，只有最新请求可以激活或应用偏移；缓存恢复必须匹配所请求轨道和请求序号。保持原始轨道缓存和原生基准偏移分工。长字幕查询采用安全的结束边界索引，不能由固定起点窗口跳过仍然有效的重叠区间。

原生字幕隐藏类归属于实际修改的容器，替换时先恢复旧容器，再按当前闸门状态应用到新容器。覆盖视频切换、迟到响应、长短 cue 重叠和容器替换；RAF 激活条件继续保持按需运行。

### 网格调度与增量处理（B13、B14）

排队重排捕获生命周期代次，停用、重启或路由变化后旧任务不能改动新状态。仅能证明为尾部追加时走增量路径，中段插入走完整重排，所有物理搬运继续使用静默锁和可恢复锚点。

### 异步动作、下载目标与弹窗结算（B15–B17、B19）

动作发起时保存下载 URL，使用 URL 参数编码保留完整地址；等待确认后仍使用该目标。PiP、截图、三个下载入口均返回完整操作 Promise，由工具栏统一持锁、错误处理和释放状态。

确认弹窗关闭后依次执行用户动作回调和关闭回调，各执行一次；任一回调抛错仍执行另一个，并以首个异常拒绝 Promise。已有无回调调用方的返回值保持不变。

## 实施边界

按模块并行修改，文件所有权互斥。负责方同时维护该模块回归测试；不改依赖、锁文件、用户脚本权限或已确认架构约定。主代理负责共享变更集复核、全量检查、文档对齐及按功能边界提交。

## 验证

- 定向测试覆盖每个 B 编号对应的触发链，另覆盖正常流程、取消/销毁和必要的错误恢复。
- 运行 `pnpm check`、`pnpm test`、`pnpm build`。若用户级 pnpm 配置权限仍阻断执行，使用现有本地工具执行等价脚本并报告实际命令，不安装依赖。
- 现场验收覆盖快速导航、功能连续启停、当前页与隐藏旧页并存、字幕切轨、双标签页改设置、下载确认期间导航。未取得浏览器证据时明确保留该限制。
