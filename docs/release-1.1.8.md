# 1.1.8 版本发布说明

发布日期：2026-10-05。本补丁版本包含第三轮审查确认的 12 项缺陷修复，以及章节和原生互动面板的生命周期协调。

## 更新内容

- 字幕有效空轨道清空旧显示，损坏 JSON/XML 正确结算失败；按请求序号恢复有效缓存，包括此前成功的空轨道。
- 字幕请求读取响应副本，停用与异常回退保持原响应可读取；HTTP 204/205 保留无正文成功语义。视频和语言参数中的下划线保持正确身份归属。
- 默认字幕偏移在存储成功后提交，设置写入失败显示本地化错误并支持重试；启用功能后同步已保存数值，保留正在编辑的输入。
- 工具栏在相同目标下同步新增、移除和替换动作，复用按钮并调用当前登记回调；Shorts 下载入口支持原生按钮键盘操作；路由切换刷新动作可见性。
- 网格逐批追加与完整计算保持布局一致，多个未补齐分区使用完整重算；离开路由立即撤销旧观察器和排队任务。
- 页面端销毁时移除视频 loadstart 监听，重新启动保持单份监听；当前语言补充翻译立即更新查询与快照；已有 Tab 接收语言命令后原地更新文案并保留用户状态。
- 章节和互动面板先完成 YouTube 原生初始化再接入 Tabview，保留原生面板标识；切换 Tab 通过原生命令关闭已展开面板，面板展开期间协调右栏布局。

## 安装与升级

在 Tampermonkey 或 Violentmonkey 中安装发布附件 `youtube-turbo.user.js`。已有配置保持兼容。

## 验证

- 本地严格类型检查、49 个测试文件中的 443 项测试、生产构建通过。
- GitHub Actions 在 Windows/Linux 执行类型检查、完整测试和生产构建；发布附件取自对应版本提交通过 CI 后生成的 Ubuntu 构建产物。
- 四个独立子代理完成修复复审，字幕身份与缓存边界另外完成定向复核。
- 真实 YouTube/油猴端到端验收尚未完成，自动化验证边界见 [第三轮修复报告](project-third-repair-report.md)。
