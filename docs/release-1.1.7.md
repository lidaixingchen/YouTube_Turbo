# 1.1.7 版本发布说明

发布日期：2026-10-05。此补丁版本包含第二轮全面审查确认的 12 项缺陷修复及交叉审查确认的生命周期边界修复。

## 更新内容

- 功能注册表统一调度播放器和下载初始化，保存为关闭的循环、下载功能在刷新后保持关闭；播放器读取设置失败可以重试。
- 下载校验当前 watch/Shorts 视频身份并保留操作开始时的完整地址；HUD 归属当前播放器，切换时清理旧节点与动画。
- Tabview 完善锚点丢失、源节点移除和旧路由断连后的内容恢复；注入空值或异常使用备用脚本，相同会话重复注入保持一次执行。
- 字幕请求失败、中止、超时及 HTTP 错误正确结算缓存恢复权；复用 XHR 和停用时释放请求监听器。
- 工具箱与倍速菜单支持原生按钮、键盘导航和可见焦点，菜单上下文抑制播放器全局快捷键。
- 补齐 33 份运行时语言字典的全部 69 个基础键，覆盖元数据语言标签，设置菜单入口同步本地化。
- Windows 页面端开发更新正确传播，esbuild 依赖纳入 watcher；GitHub Actions 在 Windows/Linux 执行类型检查、全量测试、生产构建并保存脚本产物。

## 安装与升级

在 Tampermonkey 或 Violentmonkey 中安装发布附件 `youtube-turbo.user.js`。已有配置保持兼容。首页及订阅页迷你播放器没有可靠视频身份时，下载入口保持隐藏。

- 本地严格类型检查通过，48 个测试文件、410 项行为测试通过，生产构建通过。
