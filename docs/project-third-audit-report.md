# 第三轮隐蔽缺陷审查报告

审查日期：2026-10-05。基线：`v1.1.7`，提交 `df12a600368518f5643cc560bc2af0467c4141e2`。

## 结论与适用范围

本轮通过 9 个并行子代理审查生命周期、异步结算、DOM 归属、增量计算、公开注册接口和跨上下文边界，再补充定向复现。确认 12 项实现缺陷：7 项 P2、5 项 P3。没有确认 P0/P1 问题。

最值得优先处理的是字幕成功状态与解析结果脱节、停用期间改变原生请求结果、网格增量布局与完整计算不一致，以及页面端销毁后仍执行的视频暂停监听。这些问题分别破坏数据有效性、请求透明性、计算一致性与生命周期撤销契约。

“确认”指源码因果链与定向复现成立，并不意味着所有触发组合都已在真实 YouTube 页面出现。表格区分内置路径、异常路径、公开接口和协议接口；公开接口问题不应被描述为当前所有用户都会遇到的故障。真实 YouTube/Tampermonkey/Violentmonkey 端到端验收尚未进行。

本轮仅审查、复现和报告，没有修复生产代码，也没有提交或发布。审查期间工作区存在另一组 Tabview 修改及页面预览文件；这些内容已保留，报告的行号与结论以发布基线为准。第二轮已修复事项见[第二轮修复报告](project-second-repair-report.md)，本报告只列新的触发机制。

## 缺陷证据与修复验收边界

### H01：已挂载工具栏保留旧动作与旧回调

位置：[ToolbarController](../src/ui/toolbar/toolbar.ts)，基线 430–455、495–533 行；[SlotMountBus](../src/ui/toolbar/slot-mount-bus.ts)，240 行附近；[渲染器](../src/ui/toolbar/renderers.ts)，189 行附近。

插槽和目标容器未变化时，挂载总线直接返回，Shorts 与元数据插槽也没有刷新已渲染动作。按钮闭包捕获了旧 `action`。点击处理虽然按 ID 查询当前登记记录，最终调用的仍是闭包中的 `action.onClick`。

复现保留同插槽的另一个合法动作，再替换同 ID 配置：原按钮执行旧回调；注销旧 ID 并注册新 ID，则旧按钮仍在、新按钮缺失。补充复现使用真实 `VideoDownloadService.enable/disable` 与公开注册的同插槽兄弟动作，两个用例通过。

当前内置 Shorts/元数据插槽各只有下载动作，缺少兄弟动作时整插槽撤销可以掩盖问题。因此这是已确认的多动作登记契约缺陷，不能推导为当前每次开关下载都失效。

验收：相同挂载目标下的新增、移除、同 ID 配置替换必须同步到 DOM；已存在按钮必须调用当前登记回调；保留兄弟动作时也应成立。

### H02：Shorts 下载入口无法通过键盘操作

位置：[Shorts 渲染器](../src/ui/toolbar/renderers.ts)，基线 177 行附近。

下载入口使用仅监听 `click` 的 `div`，没有可聚焦行为、按钮语义或键盘激活处理。键盘用户无法用 Tab 进入，也无法用 Enter/Space 激活。第二轮修复的工具箱和速度按钮没有覆盖这个独立入口。

验收：下载入口应具有按钮语义、可聚焦性和标准键盘激活行为；鼠标与键盘触发同一动作，且一次操作只执行一次。

### H03：空轨道与解析失败提前结算为成功

位置：[字幕时间轴](../src/features/caption/timeline.ts)，基线 140–145、282 行附近。

轨道在解析之前被标为成功，只有解析出非空 cues 时才更新当前轨道。先摄入有内容的英语轨道，再收到最新翻译轨道 `{"events":[]}`，旧英语仍作为当前覆盖层内容。最新轨道身份已变化，显示数据却没有随之清空。

格式损坏的 2xx 内容也会走解析异常到空 cues 的路径，但成功状态已经提交；后续失败结算不能纠正这一状态，缓存恢复依赖的成功轨道身份因此失真。

验收：有效空轨道应成为明确的空结果并撤销旧显示；解析失败应结算失败；成功、空结果和解析失败必须具有一致的轨道身份与恢复语义。应同时覆盖切换语言、切换翻译轨道和清空后恢复。

### H04：默认字幕偏移保存失败后内存已经改变

位置：[字幕控制器](../src/features/caption/controller.ts)，基线 139–146 行；[设置面板](../src/registry/settings-view.ts)，415 行附近。

设置方法先修改 `globalDefaultOffsetMs`，随后调用同步存储写入，最后才 `applyChange()`。若写入抛错，内存已变、持久值仍旧、应用通知没有发生。后续请求读取新偏移，现有显示和设置反馈却可能仍按旧状态工作。数值设置写入路径没有处理这一异常。

验收：持久化失败时保持原来的有效状态，或完成明确的一致性处理；设置面板应呈现失败且允许重试； getter、后续请求和当前渲染不能分别使用不同状态。

### H05：网格布局随内容加载批次改变

位置：[布局计算器](../src/features/grid/calculator.ts)，基线 69–73 行；[网格协调器](../src/features/grid/coordinator.ts)，250–257、298 行附近。

完整扫描会覆盖此前的待补充分区，增量状态只保留最后一个待处理尾部分区。多个分区尚未补齐时，逐批追加只继续最后一个分区，无法完成完整计算会执行的前部分区补齐。

以四列布局复现：初始源内容为 `[A,B,S1,C,S2]`，其中字母为视频，S 为分区。通过原生 MutationObserver 分三批追加 D、E、F，得到 `[A,B,S1,C,D,E,F,S2]`；恢复源锚点后对相同最终内容做完整计算，得到 `[A,B,C,D,S1,S2,E,F]`。布局因加载批次而变化，下一次完整重算还会造成位置跳变。

验收：增量计算是性能优化，必须保持与同一最终源内容的完整计算等价。应覆盖多个待补分区、多批追加、不同列数和 resize 后重算。

### H06：迷你浏览器销毁后仍暂停其他视频

位置：[MinibrowserRouter](../src/features/tabview/page/minibrowser-router.ts)，基线 56、165–188 行。

`ensureLoadStartListener()` 安装 document 捕获监听，但 `destroy()` 没有移除它，也没有使处理函数失效。收到主视频 `loadstart` 时，监听会暂停其他匹配视频。功能关闭后仍可执行这一副作用；重新创建页面端实例还可能叠加监听。

定向复现在销毁后触发 `loadstart`，其他视频的 `pause()` 仍被调用一次。它与其他页面端会话撤销机制不同，应独立处理。真实影响要求页面同时存在匹配的其他视频，频率尚未现场测量。

验收：销毁后的事件不得暂停任何视频；重新初始化只能存在当前实例的一份有效监听。

### H07：停用字幕功能使合法空响应变成请求异常

位置：[TimedTextInterceptor](../src/features/caption/interceptor.ts)，基线 237–247、250–273 行。

拦截器读取 `response.text()` 后，如果生命周期已经失效，使用读出的字符串重建 Response。HTTP 204/205 的正文必须为空对象意义上的 `null`；空字符串仍是非 null 正文，`new Response("", { status: 204 })` 会抛 `TypeError`。[Fetch 标准](https://fetch.spec.whatwg.org/#initialize-a-response)明确规定这个构造约束。

该失效分支位于后面的异常处理之外。原生 fetch 已经成功，但在读取正文的 await 间隙停用字幕功能，就把成功 Promise 变成拒绝。当前生命周期分支也尝试相同构造，不过异常会被捕获，因此两个分支结果不同。

主代理使用原生 `Response(null, { status })`，分别覆盖 204、205，并通过微任务在读取期间执行 `destroy()`：两个用例均复现请求拒绝；同一个原生响应自身的 `.text()` 正常返回空字符串。没有注入非法正文，也没有依赖业务回调抛错。

验收：停用前后保持原生合法响应的成功结果和正文语义；无正文成功状态不应摄入失败轨道或产生构造异常。YouTube 字幕接口实际返回这两种状态的频率尚未采样，当前确认的是合法网络输入下的拦截契约。

### H08：启用字幕后设置框仍显示旧偏移

位置：[字幕控制器](../src/features/caption/controller.ts)，基线 72–81 行；[设置面板](../src/registry/settings-view.ts)，229–234、387、428–437 行。

字幕启动时关闭，控制器尚未加载已保存偏移；设置面板先从初始内存值生成数值框。随后启用功能，控制器加载保存值，但行刷新只处理可用性，没有同步数值框。例如保存 600 ms，面板先显示 0，启用后实际使用 600 ms，框仍显示 0。

这是显示与实际值不一致。加减按钮使用 `field.getValue()`，不能据此声称它会从显示的 0 计算并覆盖已保存的 600。

验收：功能初始化完成后同步已打开设置框的数值；加减、输入和实际渲染统一使用同一有效值。

### H09：离开网格路由后旧观察器继续唤醒任务

位置：[网格协调器](../src/features/grid/coordinator.ts)，基线 113、148–170、441、486–495 行；[ScopedGridObserver](../src/features/grid/scoped-observer.ts)。

导航重置清空当前目标，但没有断开旧观察器；新路由不存在网格或宿主时，挂载流程提前返回。保留的旧目标继续发生突变，回调仍会安排当前代的完整重排任务。定向原生 MutationObserver 复现确认这种唤醒存在。

在查询不到网格时任务通常会提前结束，不能宣称每次都发生错误重排；已经确认的是闲置期继续接收过期 DOM 事件，违反离开路由后停机的契约。

验收：离开支持路由立即 disconnect；旧目标后续变更不再安排工作；重新进入路由后监听当前目标。

### H10：当前语言补充翻译后仍读取旧字典

位置：[Locale](../src/i18n/index.ts)，基线 39、46–48、64–74 行。

当前语言选定后保存字典对象引用。`registerTranslations()` 创建并替换字典对象，却未同步当前引用。因此向当前语言注册新键或覆盖文案后，`t()`、方向信息和快照仍读取旧对象。

公开接口定向复现成立。当前内置调用路径没有动态调用此注册方法，影响主要是接口扩展契约。

验收：向当前语言注册翻译后，查询与快照立即反映新内容；其他语言注册不能改变当前语言。

### H11：页面收到语言更新后已有 Tab 标签保持原文

位置：[页面端命令入口](../src/features/tabview/page/index.ts)，基线 57–70 行；[页面协调器](../src/features/tabview/page/coordinator.ts)，161–165、392–399 行；[DOM 搬运器](../src/features/tabview/page/relocator.ts)，107–112 行。

`update-locale` 命令到达页面协调器并更新 locale，但重新挂载路径只协调插槽。Tab 标签只在创建容器时渲染；已有容器的标签不会更新。补充复现通过实际命令入口验证：语言更新方法被调用，已挂载 Info 标签仍保留原文。

沙箱当前只发送初始语言快照，没有正常 UI 路径发送这个更新命令。因此本项是协议实现缺陷，不能描述为当前已提供的实时语言切换功能全面失效。

验收：已有容器收到语言更新后刷新标签与相关可访问名称；保留活动 Tab、插槽节点和用户状态。

### H12：自动推导轨道视频 ID 时截断合法下划线

位置：[字幕时间轴](../src/features/caption/timeline.ts)，基线 215 行附近。

`ingest` 在省略可选 `videoId` 时，从复合 key 按第一个下划线切分。视频 ID 自身可含下划线，例如 11 字符的 `ab_cdEFghij`，结果会被推导为 `ab`。轨道因此归属错误，正确视频的待处理状态与缓存恢复不能正常完成。

控制器当前显式传入 videoId，内置主路径受到保护；缺陷位于该方法声明支持的省略参数分支。包含下划线的 ID 定向复现成立。

验收：省略参数时准确恢复合法视频身份，或使用无歧义的显式身份契约；同时覆盖含下划线、连字符及常规字符的 ID。

## 仍需现场样本的边界

以下实现分支已经发现风险，但缺少足够证据确认真实上游触发方式，未计入 12 项：

| 边界 | 已有证据 | 仍需补充的关键证据 |
| --- | --- | --- |
| Tabview 上游节点替换、重新归属，或 Tab 容器被单独移除 | 旧节点仍连接时的提前返回、旧源位置记录、单独移除容器后的恢复阻塞均可构造 | YouTube 实际替换顺序、是否直接移除脚本容器；应区别于第二轮已修复的整页根节点脱离 |
| Shorts 活动视频与已绑定播放器对象分离 | 活动 reel 改变但旧 video 仍连接时，调速可继续作用于旧对象；其他 video 的 play 还能重新绑定 | 真实活动标记和 play 事件顺序，避免重复统计上一轮同类句柄风险 |
| 路由切换后工具栏可见性保持旧结果 | 复用同一个 player 容器进入迷你播放器时可保留下载按钮 | 真实 YouTube 是否复用该目标；当前下载 URL 校验仍阻止非法下载 |
| GM_addElement 返回其他 realm 的元素 | 跨 realm 的 instanceof 判断可失败并触发再次注入 | Tampermonkey/Violentmonkey 实际返回值 realm 与 CSP 行为；会话守卫已限制重复启动 |
| 网格目标容器自身替换、静默窗口与上游突变混合 | 观察器不观察目标父级，静默闸门会忽略合并的通知批次 | 实际同路由替换或同步重入样本，以及完整快照是否已经包含对应变更 |
| 字幕摄入回调抛错后的响应回退 | 正文已消费后返回原响应，页面再次读取可失败 | 当前摄入回调发生异常的实际来源；H07 不依赖此条件 |
| 链接评论参数、调速非有限值与自动更新来源 | 特殊 lc 字符可使选择器抛错；NaN 会穿过调速限幅；发布附件 URL 的更新行为需要验证 | 合法上游输入来源、实际油猴更新检查结果；不得按构造输入直接推断正常页面普遍故障 |

GM API 与 realm 边界参考：[Tampermonkey 文档](https://www.tampermonkey.net/documentation.php?locale=zh_CN&q=GM_addElement)、[MDN instanceof](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/instanceof)。这些资料说明接口与语言行为，不能代替真实扩展环境采样。

- 网格：首批六个原生 MutationObserver 复现通过，补充一个批次等价性复现通过。
- 播放器：四个条件性复现通过。
