# 0007. 功能状态按独立键持久化

- **状态**：已采纳
- **日期**：2026-10-04

## 上下文

功能开关可在多个 YouTube 标签页中修改。GM 存储提供值变更通知，但没有整对象读改写事务或跨标签页 CAS。各标签页的本地生命周期队列只能串行化本地工作，不能保证整份配置对象的并发写入隔离。

## 决策

每个功能的布尔选择保存在 `yt/functionState_01/<featureId>`，键名统一由 `StorageKeys.youtube.functionStateForFeature(id)` 生成。一次修改只写入该功能的独立键，功能 ID、描述符顺序及公开设置接口保持一致。

旧键 `yt/functionState_01` 保留为兼容读取来源。独立键缺失时使用旧对象对应字段，字段缺失或不合法时使用描述符默认值；独立键存在时优先使用独立值，非法独立值按描述符默认值规范化。读取和初始化不写入迁移数据，避免迁移过程覆盖其他标签页刚提交的选择。

注册表监听旧键和所有已注册功能键。远端通知只表示需要重新读取可见快照，通知携带值不作为有序命令执行。读取失败时保留同步需求，在后续通知、显式缓存刷新或页面恢复可见时重试，不使用轮询。初始化失败释放本轮存储和可见性监听资源。

## 影响与边界

不同功能的并发修改由独立键隔离；同一功能仍遵循最后持久化值。旧版本标签页写旧对象时，已经具有独立键的功能继续使用独立选择，因此升级后的标签页不承诺同步旧版本对这些功能的修改。

每个功能增加一个值监听器，资源数量与注册功能数量对应。注册阶段结束后仍按现有约定固定描述符集合；本地 hook 串行化、target/applied 区分、requiresReload 及设置反馈契约保持一致。

回归测试位于 [注册表测试](../../src/registry/__tests__/feature-registry.test.ts)，覆盖并发不同字段、兼容回退、独立键优先、初始化不写入、失败恢复和监听清理。
