# 第五轮缺陷修复方案

基线：`v1.1.9` / `c7ae139`。范围：[第五轮审查报告](project-fifth-audit-report.md)确认的 K01–K03。

## 设计与验收

| 问题 | 实现边界 | 验收 |
| --- | --- | --- |
| K01 | Tabview 标签与字号控件采用原生按钮；控件平级组合，避免交互嵌套；同步可访问状态、焦点样式及多语言名称 | 鼠标与键盘均可使用；焦点可达；一次激活只触发一次；评论计数、语言更新、字号限幅与布局兼容 |
| K02 | 保留现有参数转义约定，用替换回调插入参数字面值 | 美元替换序列、普通文本、数字、HTML 字符和重复占位符结果正确 |
| K03 | 以原生 open 成功作为旧请求撤销与新请求登记的事务边界；协调原生同步事件中的 send/open 重入 | 失败重开保留旧请求；成功重开撤销旧请求；同步重入请求拥有正确身份；响应头装饰与销毁契约保持一致 |

三项按独立模块并行实施，收齐后统一审查与验证。生产改动及回归测试分别限定在 Tabview/相关语言标签、翻译插值、字幕网络拦截范围。

## 验证与交付

运行针对性回归、`pnpm check`、完整 `pnpm test --maxWorkers=2` 及 `pnpm build`；完成后更新修复验收报告。按模块分批提交并推送，核对远端提交及 Windows/Linux CI。真实 YouTube、油猴管理器及辅助技术验收单独列明；尚缺生产触发证据的候选行为保留审查结论。
