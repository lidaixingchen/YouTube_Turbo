# 第四轮缺陷修复方案

日期：2026-10-07。范围：[第四轮审查报告](project-fourth-audit-report.md)的 J01–J08。用户已授权全面修复。

## 实现与验收契约

| 项目 | 实现边界 | 必须验证的行为 |
| --- | --- | --- |
| J01 字幕轨道所有权 | 时间轴记录活动轨道身份；当前视频切换不同轨道时撤销旧显示，保留缓存和请求序号恢复机制；同轨刷新保留有效内容 | 新语言等待时为空，失败后恢复有效缓存；其他视频预取不清空当前显示；旧响应不覆盖新所有者 |
| J02 异步动作互斥 | 移除只释放锁而未取消业务的定时策略；Promise 结算后释放锁；保留销毁和重新注册的代际隔离 | 用户长时间确认不会再次执行；取消和异常后可重试；旧完成不能释放新执行锁 |
| J03 模态焦点 | 现有模态容器增加 dialog 语义、可访问名称、初始焦点、Tab 环绕、后台焦点约束和关闭恢复；最上层弹窗拥有键盘处理权 | 下载与设置弹窗打开后焦点在内部；工具箱关闭不夺走弹窗焦点；叠加弹窗只关闭最上层，焦点正确恢复 |
| J04 安装入口 | README 安装版本、附件地址与发布说明同步本次交付的 1.1.9 | 文案、附件版本和说明一致 |
| J05 JSON3 片段偏移 | 事件起点裁剪到零时，同步裁剪片段相对偏移，使平移后的绝对时间一致 | 跨零片段、缺省偏移、完全过期事件和正常事件 |
| J06 字号协议 | 页面沿用协议的 10–24px 范围，常量来自共享契约；通知发送实际限幅后的字号 | 配对会话接受全部按钮事件，上下限连续点击值与页面一致 |
| J07 频道路径 | 解析 URL 路径结构以支持合法编码的国际化 handle，保留原生导航委托和任务取消机制 | 中文、日文、阿拉伯文、ASCII、合法分隔符 About 路径，以及导航覆盖旧任务 |
| J08 响应语义 | 改写正文时使用真实 Response 并保留 url/type/redirected 与 clone 的元数据；协调失效的表示头；XHR 仅在正文改写成功后同步响应头读取 | 正文读取和 bodyUsed 保持原生行为，clone 仍可独立读取；fetch/XHR 头部一致；零偏移、停用、失败与 204/205 仍返回原始结果 |

所有新增变量、参数与返回值显式声明类型，新常量进入模块 constants.ts。页面端继续保持与油猴沙箱隔离；没有增加常驻轮询或全局 MutationObserver。响应兼容通过原生对象及局部属性处理，不引入 Response 代理。

## 分工与验证

字幕显示、字幕网络改写、工具栏与模态、Tabview 协议与导航分别由独立子代理负责，文件归属互不重叠。主代理维护安装入口与交付文档，收齐实现后整合。修复后由独立子代理按正常行为复核，不以重复实现断言代替验收。

子代理使用工作区 Vitest 入口执行定向测试；主代理依次执行 `pnpm check`、`pnpm test --maxWorkers=2` 和 `pnpm build`，避免多个 pnpm 同时启动。文档相对链接及 `git diff --check` 一并检查。真实 YouTube/Tampermonkey/Violentmonkey 验收仍需现场环境，自动化结果按实际范围报告。

本轮交付按模块分批提交并推送，最终版本提交在 Windows/Linux CI 全部通过后，使用对应 Ubuntu 构建产物发布 1.1.9。审查报告中的条件性边界仍需上游证据。
