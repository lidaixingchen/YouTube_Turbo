# 第三轮缺陷修复方案

目标：落实[第三轮审查报告](project-third-audit-report.md)中 H01–H12 的验收条件，保持当前架构和已有 Tabview 工作区改动。

## 模块设计

| 模块 | 问题 | 实现边界 |
| --- | --- | --- |
| 字幕时间轴与请求拦截 | H03、H07、H12 | 解析完成后结算有效轨道；有效空轨道撤销旧显示；解析失败进入失败恢复路径；保留无正文响应语义与停用后的原生成功结果；省略身份参数时使用请求、缓存或当前路由的完整视频身份，缓存记录视频 ID |
| 字幕偏移与设置 | H04、H08 | 存储写入成功后提交有效偏移；失败显示现有国际化反馈并允许重试；初始化状态变化时同步数值框，保留正常编辑语义 |
| 工具栏 | H01、H02 | 同目标挂载期间协调所有插槽动作，按钮执行当前登记配置；Shorts 动作使用可聚焦、可访问的原生按钮行为；维持执行锁、销毁和异步隔离 |
| 网格 | H05、H09 | 只有满足完整计算等价条件才使用尾部增量；其他情况恢复源锚点后完整计算；离开路由立即撤销旧目标观察，不引入轮询 |
| 页面生命周期与语言 | H06、H10、H11 | loadstart 监听由实例持有并在销毁时移除；注册翻译同步当前字典；已有 Tabs 在语言更新时更新文案和可访问名称，保留活动标签、DOM 插槽和用户状态 |

## 协作与验证

按上表分成五个独立修改范围，子代理明确授权范围内的源码与回归测试写入。不得撤销其他人的修改，不得派生子代理。现有 Tabview 改动涉及原生面板协调；语言修复仅在所需方法中增量修改。

每个模块运行定向回归测试与类型检查。全部整合后运行 `pnpm check`、`pnpm test --maxWorkers=2`、`pnpm build`，再由独立子代理只读审查修改与测试。修复中发现的同一因果链问题一并处理；需要真实上游样本的边界不作为未经验证的重构依据。

最终记录 H01–H12 的落实情况、测试结果及真实浏览器验收边界。源码、测试与文档按模块分批提交，远端 CI 通过后发布 1.1.8，发布附件采用对应提交的 CI 构建产物。
